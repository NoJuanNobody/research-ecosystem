What is research-ecosystem and what is it like to use?

Long image

A

Answer

It is a research sketchbook: a catalog of 36 paper ideas and a small Python CLI. The CLI runs a toy model for each idea and fills a LaTeX manuscript template. It is a prototype, not production software or finished research.

  1. One command lists, inspects and "verifies" the 36 ideas; each check is a short pure-Python model with fixed inputs.1
  2. A latex command writes main.tex, references.bib and a build script per paper; 39 bundles with PDFs are committed.2
  3. A graph-loop command simulates a 5-stage research cycle and writes a SLURM script, but it submits nothing and its metrics come from a formula.3

  1. Install package ↗

    Run pip install -e . in a clone. It adds the research-ecosystem command and needs no API keys or extra packages.

  2. List 36 papers ↗

    research-ecosystem list --pillar 2 prints ID, title, runtime and target metric, for example [15] Non-Executive World Bible Consistency Monitors.

  3. Inspect one paper ↗

    research-ecosystem inspect 15 prints its files and runs its toy model: Verification: PASS with metrics such as caught_violations_count: 3.

  4. Verify all + scenarios ↗

    research-ecosystem verify-all prints Verified 36/36 papers and 3/3 cross-pillar scenarios. scenario A chains 12 papers into the "1-person animation studio" story.

  5. Write LaTeX bundle ↗

    research-ecosystem latex 15 writes main.tex, references.bib and compile_pdf.sh under papers_latex/. The PDF builds if tectonic or pdflatex is installed.

  6. Run graph loop ↗

    research-ecosystem graph-loop --topic "..." prints a JSON graph of 5 stages and writes a paper 37-style bundle plus a .slurm file.

What does "PASS" actually mean?

Read results as demos, not measurements

Each paper's check runs a short model on hand-picked inputs and tests its own condition. Paper 01 computes throughput as 28 × (1 + accepted tokens) and passes when that exceeds 120.4 The graph loop sets measured speed as 58 × (1.8 + 0.45 × iteration) and the p-value as 0.008 / iteration; it does not run the SLURM job it writes.3 Its "frontier lab" papers are a fixed list in the code, not a live arXiv search, and those IDs were not checked.5 The 36 core manuscripts share one abstract template and one generic loss equation, so the PDFs are drafts to fill in, not results.2
